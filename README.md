# Room Finder

Room Finder is a simple **PHP and MySQL web application** for finding and viewing rental rooms.

## Features

*  View available rooms
*  View room details
*  View room location and rent
* User registration and login
* PHP session-based authentication
*  Contact form
*  Room images
*  Responsive design

## Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript
* Bootstrap / Font Awesome

**Backend**

* PHP
* MySQL
* MySQLi
* PHP Sessions

**Tools**

* Node.js
* npm
* Gulp
* Bower

## Database

Database name:

```text
login
```

Main tables:

```text
store
contact
```

The `store` table manages users, while the `contact` table stores contact messages.

## Installation

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project into:

```text
C:\xampp\htdocs\roomfinder
```

4. Create a MySQL database named:

```text
login
```

5. Create the required tables.
6. Open the project in your browser:

```text
http://localhost/roomfinder/output/html/index.php
```
